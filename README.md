# github-final-project

A calculator that calculates simple interest given the principal amount, annual rate of interest, and time period in years.

## Input

- `p`: Principal amount
- `t`: Time period in years
- `r`: Annual rate of interest

## Output

Simple interest = `p * t * r / 100`

## Example

If the principal is 1000, the annual interest rate is 5%, and the time period is 2 years:

Simple interest = `1000 * 2 * 5 / 100` = 100

## Usage

Run the `simple-interest.sh` script and enter the principal amount, time period, and annual rate of interest when prompted.
